# Chapter 3 Cryo Mist Effects

This folder contains the imported visual-only mist assets used by Chapter 3, the cryogenic storage zone.

Imported assets:
- `noise/Noiselong.png`: low-alpha drifting floor fog.
- `smoke/smoke_bright_gray/smoke9`
- `smoke/smoke_bright_gray/smoke10`
- `smoke/smoke_middle_gray/smoke9`
- `smoke/smoke_middle_gray/smoke10`

Usage rules:
- These assets are only used by Chapter 3 cryogenic room visuals.
- Fog and smoke are visual-only nodes with no collision, damage, navigation, or objective logic.
- Do not use additive glow or bright cyan tinting; the intended look is low, pale, slow cryo mist.
- Do not use these assets as full-screen smoke, poison gas, magic circles, or explosion smoke.
