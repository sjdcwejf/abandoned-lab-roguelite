# 生化协议：熵区

《生化协议：熵区》是一款面向 Steam 的 2D 像素风、俯视角/斜俯视角、房间制动作 Roguelite 原型。故事发生在极渊岛地下封存设施：一座被熵区吞没的企业生物工程基地。

当前设计方向：

- 主题：生化恐怖、企业阴谋、异星原质、适应性实验体
- 核心循环：进房间、清怪、捡武器、形成构筑、死亡重开
- 引擎：Godot 4
- 当前武器原型：校准激光笔、封控钉枪、能量光剑、动力拳套、检疫刃、检疫霰弹枪、破门电锯

设定与文档来源优先级：

- `docs/前期故事梗概与人物信息.md`：长期剧情、美术和角色方向来源。
- `docs/角色设定.md`：记录当前可玩角色铁幕、流影、蜂群、蚀瞳。
- `docs/剧情设定_生化协议_熵区.md`：当前世界观与章节包装来源。
- `docs/状态效果系统.md`：状态效果系统说明。
- `docs/武器路线设计.md`：记录全流程武器路线、章节武器池和至少 14 种非初始武器规划。
- `docs/中文文本与字体规范.md`：中文文本、字体和编码规范。

本项目当前基于 Quiver 的 Tiny Wizard Demo 与 Top-Down Shooter Core 改造。来源和许可见 `LICENSES/THIRD_PARTY_NOTICES.md`。

## 当前可玩实验体

- 铁幕：防线型适应性实验体。高生命、移动较慢，初始武器为校准激光笔；主动技能为铁幕协议，被动可以定期吸收伤害。
- 流影：高速游击型实验体。低生命、高移速，初始武器为封控钉枪；拥有闪避概率、移动残影、动量加速与相位突袭。
- 蜂群：无人机控制 / 战术支援型实验体。中等生命、能量上限较高，当前原型暂用能量光剑作为占位初始武器；主动技能为蜂群指令，被动可以通过武器命中回收集群能量。
- 蚀瞳：腐蚀污染型实验体。中等生命、较高能量，初始武器为校准激光笔；主动技能为蚀瞳凝视，被动可以让武器命中附加腐蚀持续伤害。

## 当前操作

- 开始游戏：从主菜单进入角色选择，选择铁幕、流影、蜂群或蚀瞳；被选实验体会从封存协议唤醒区的休眠仓苏醒。
- 移动：WASD
- 瞄准：鼠标
- 主攻击：鼠标左键
- 旧版方向射击：方向键
- 放置破障炸药：E
- 角色技能：Q
- 副攻击：鼠标右键
- 切换武器：拾取后按 1 / 2 / 3 / 4
- 预留冲刺键：Space
- 交互 / 打开宝箱 / 进入裂隙 / 拾取武器台物品：F
- 打开 / 关闭背包：I
- 暂停 / 继续：Esc

暂停菜单提供继续游戏、设置、放弃本次游戏和返回主菜单。放弃本次游戏与返回主菜单前都会二次确认；放弃后会清空当前探索构筑和物资，仅保留最初选择的角色，并回到教学完成后、第一章正式关卡开始前。当背包处于打开状态时，第一次按 `Esc` 只会关闭背包。主音量、音乐、音效、窗口 / 全屏和语言设置会保存在本机，下次启动时继续使用。当前语言入口支持中文与英语，主菜单、暂停菜单和设置面板已接入第一版双语刷新。

武器快捷栏固定为 4 个可访问槽位。正式关卡中，与地面武器交互或在渡鸦商店购买武器前，会先显示武器对比确认面板。若还有空槽，可按 `F` 加入；若四槽已满，可按 `1 / 2 / 3 / 4` 自行选择要替换的槽位；商店只会在确认后扣除原质，新武器随后立即装备。

当前交互反馈已统一：宝箱、渡鸦商人、地面武器、武器台和下行裂隙都会在靠近时显示明确按键或锁定原因。原质、遗物、红心、护盾、破障炸药和生物识别钥仍然保持触碰吸收；它们的成功、满血、无法拾取等短提示只在教学关卡显示，正式关卡保持更干净的战斗界面。

## 当前武器原型

玩家开局会根据角色携带专属初始武器，并可在流程中拾取更多武器。

- 铁幕开局携带校准激光笔，生命 8，移动较慢但更稳。
- 流影开局携带封控钉枪，生命 5，移速很高，有 15% 闪避概率。
- 蜂群开局暂携带能量光剑，生命 6，能量上限较高；后续会扩展为无人机控制器和支援模块。
- 蚀瞳开局携带校准激光笔，生命 6，能量 110，擅长腐蚀持续伤害。
- `1`：初始远程武器，按住或点击鼠标左键朝鼠标方向攻击。
- `2`：能量光剑，鼠标左键挥出短距离可见斩击。
- `3`：动力拳套，鼠标左键近距离出拳，鼠标右键从下方枪口发射能量弹。
- `4`：检疫刃，在封存协议唤醒区从渡鸦留下的武器台拾取后解锁。

流程中还可以从渡鸦军械缓存或渡鸦检疫商店获得“检疫霰弹枪”和“破门电锯”。检疫霰弹枪一次发射 5 枚短射程原质弹丸，适合贴近目标后进行扇形爆发；破门电锯按住攻击键会持续切割前方短距离区域，适合近身压制和打消敌方弹幕。

正式关卡武器房和渡鸦检疫商店现在共用同一份章节武器目录。当前第一章武器池先接入已实装武器，后续新增武器时优先登记到 `res://tiny_wizard/player/weapons/weapon_catalog.gd`，再决定它所属章节和来源。第四章“外骨骼兵器工厂”已接入武器词条 MVP：武器质检室和渡鸦军械补给站有概率生成带有“稳定”“速射”或“源质充能”的武器。稳定会提高伤害，速射会缩短开火间隔，源质充能命中时有小概率追加伤害；扩容和精准暂列 TODO。

光束、近战和投射物武器都通过目标的 `hit()` 方法结算伤害。旧版 Tiny Wizard 方向箭矢武器兼容层已移除，当前角色攻击统一由新版武器槽系统处理。

## 当前技能原型

每名实验体现在都有能量资源和一个 `Q` 主动技能。HUD 会显示技能名、能量和状态：

- 铁幕：铁幕协议。消耗 40 能量，获得临时护盾，降低受到的伤害，释放会伤害并减速附近样本的防御冲击，同时短暂提升武器节奏。
- 流影：相位突袭。消耗 30 能量，拥有 2 层充能，向前突进并穿过敌人，造成较低武器系数伤害，施加易伤，并在突进时短暂无敌。流影普通移动时只会低频留下淡蓝残影，相位突袭途经路段会留下更明显的连续残影，附近红/黑飞虫会优先锁定这些残影。
- 蜂群：蜂群指令。消耗 35 能量，释放集群信标，对附近敌人造成伤害并施加减速；这是无人机系统完成前的占位战斗表现。
- 蚀瞳：蚀瞳凝视。消耗 45 能量，释放范围污染波，对附近敌人造成少量即时伤害并施加持续腐蚀。

当前核心被动：

- 铁幕：稳定装甲，每 5 秒自动吸收 1 点即将受到的伤害。
- 流影：残影节奏，闪避或使用相位突袭后短暂提高武器节奏。
- 蜂群：集群回流，武器命中会在短冷却后回复少量能量，表现为神经集群接口回收战场数据。
- 蚀瞳：原质寄宿，武器命中会按短冷却为敌人施加腐蚀持续伤害。

当前能量系统只用于已实装主动技能的消耗和回复。角色专属升级、主动技能强化、技能变体和能量消耗构筑选择暂不进入当前开发计划；如需重启，先作为 TODO 并等待确认。

## 当前状态效果原型

项目已有通用状态效果控制器：`res://tiny_wizard/status_effects/status_effect_controller.gd`。

- 易伤：由流影的相位突袭施加，使目标受到更多伤害，并显示橙色状态环。
- 减速：由蜂群指令和铁幕协议施加，临时降低目标移动速度，并显示紫色状态环。
- 持续伤害：由蚀瞳的原质寄宿和蚀瞳凝视调用，可继续扩展到中毒、燃烧和污染区域。

## 当前交互物美术方向

第一版实验室交互物已开始替换继承项目中的奇幻地牢剪影：

- 公司黑匣子档案库：第五章关键剧情房，读取《母体诱饵假说》后解锁结局条件提示并推进渡鸦隐藏任务线。
- 渡鸦数据补给站：第五章 Boss 前固定商店房，只放置渡鸦商人和数据终端，可查看已解锁的结局条件提示。
- 母巢入口：最终章入口房，承接第五章数据中枢残骸与源质侵蚀。
- 遗物召回腔：最终章事件房，需要摧毁 3 个召回节点。
- 母体信号室：最终章剧情房，读取母体召回协议、适配筛选和渡鸦旧债最终片段。
- 渡鸦最终补给站：最终 Boss 前固定安全房，只放置渡鸦商人与最终补给终端。
- 母巢核心：最终 Boss 房，占位 Boss 为原初母体，击败后触发结局文本占位。
- 前哨回收室 / 温室守望者培育舱：Boss 房，包含 Boss 血条、冲刺追击、绿色毒液弹幕、低血量召唤和下行裂隙出口。
- 临时安全屋 / 渡鸦据点：第一章完成后的基地房间，提供遗物选择、渡鸦补给和第二章入口。

正式关卡进入房间时会显示房间目标 UI，顶部会标明当前章节和层数，例如“第一章：极渊前哨基地｜第 1 层 / 怪物房”。怪物房、奖励房和 Boss 房先使用默认清怪目标，显示当前目标、剩余样本或裂隙稳定状态。右侧简易小地图会显示当前层布局、当前房间、已探索房间，并用中文标记当前房间、Boss 房、渡鸦检疫商店、奖励房、武器房、事件房和档案房；事件房统一使用“事”标记，档案房使用“档”标记，避免不同章节事件名称挤压小地图。教学关卡和临时安全屋不显示小地图。第一章第 2 层现在会出现一个“原质污染源”事件房，玩家需要清除房内样本并击毁 3 个污染源后才能解除封锁；第二章会出现一个“虫巢样本间”，玩家需要击碎 3 个孢子囊并肃清房内样本后解除封锁；第五章会出现通讯塔控制室和卫星伪装系统两个数据事件房，用于承接终端目标和剧情档案。该入口后续会继续扩展为破坏培养舱、守卫封存终端和毒雾扩散等房间事件。

当前普通敌人包括近距离维护爬行体、泄漏浮游体和第一版远程敌人“检疫喷射体”。检疫喷射体会主动与玩家保持距离，射击前显示橙色方向预警，随后发射可被能量光剑、检疫刃和动力拳套打消的检疫脉冲。

正式关卡怪物房现在会按照主路径深度和难度预算随机组合这三类敌人。越靠后的怪物房预算越高，远程喷射体最多同时生成两只；出生点会避开入口、障碍和补给物。教学关卡仍保留固定敌人配置，不参与随机生成。

怪物房进入后会关闭可见门，清理全部敌人后重新打开。隐藏门会保持锁定，避免玩家从没有连接的出口离开生成布局。

被肃清的普通样本会掉落原质。当前 Boss 暂作为精英怪处理，死亡时会从遗物池掉落 1 个合法构筑遗物，同时产生绿色血液爆裂并开启下行裂隙。裂隙激活后需要靠近并按 `F` 进入，避免玩家站位过近时被立刻传送。原质会进入背包、显示在资源 UI 中，并作为当前渡鸦武器交易货币；遗物以海天分支的构筑遗物系统为准，会显示在左侧遗物 HUD 与背包资源栏中，并可由渡鸦回收为原质。

当前遗物已经具备第一版真实参数增强：裂殖胚核提高最大生命并保留额外原质掉落概率；菌忆伞盖提高最大能量和能量回复，并保留清房护盾 / 回复效果；空洞尾节提高移动速度；铁幕专属遗物会强化最大生命、护盾减伤或反震效果。协同遗物也会继续叠加最大生命、最大能量或能量回复。后续会继续补遗物详情面板、更多标签效果和精英怪掉落节奏。

渡鸦当前固定出现在正式封存区 Boss 前的安全屋。靠近渡鸦按 `F` 打开军械面板，面板会一次展示当前全部可购买武器；用方向键选择项目，按 `F` 进入武器对比确认，确认后购买并装备玩家尚未拥有的武器。渡鸦也会提供遗物回收选项，1 个遗物可换取 5 个原质。当本商人没有可售新武器时，终端会提示当前无武器可供购买；原质仅作为当前武器交易货币，不与破障炸药功能绑定。随机临时黑市和补给购买留到后续版本。

同一个渡鸦商人会记住玩家在交易中替换掉的旧武器，不会把刚放弃的武器立即重新上架；该记录不会跨越新一局，也不会影响未来其他渡鸦商人的独立库存。

全流程武器路线已建立文档规划：排除角色初始武器后，当前至少规划 14 种流程武器。第一章以易懂的近战、霰弹和基础控制为主，后续章节逐步加入持续区域、连锁、穿透、蓄力、回旋和终局重武器。

左上角资源栏当前只显示破障炸药和原质，生物识别钥继续作为开锁道具保留在背包逻辑中，不再占用常驻 HUD。打开背包时会额外显示原质和遗物数量。破障炸药数量大于 0 时，按 `E` 可以放置。短暂引信后会摧毁附近熵化封堵体，包括挡住奖励的检疫残骸。

当前版本角色死亡后不会立刻重生，而是先显示生命体征中断确认界面。玩家确认后会清空当前探索构筑和物资，仅保留最初选择的角色：教学关死亡会回到教学完成后的第一章正式关卡入口，正式章节死亡会退回第一章末尾的“临时安全屋 / 渡鸦据点”；也可以选择返回主菜单结束本局。

项目仍保留 `top-down-shooter-core` 的角色、交互、拾取物和必要 UI 基类；旧准星、旧 Game Over、旧弹匣和旧文本生命 UI 模板已清理，当前流程使用项目自有 HUD、暂停菜单和死亡确认界面。
