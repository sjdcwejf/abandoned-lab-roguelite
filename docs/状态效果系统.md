# 状态效果系统

本文档记录当前原型中的通用状态效果系统。它的目标是把“易伤、减速、腐蚀、中毒、燃烧、眩晕”等临时效果从角色技能和武器脚本中抽离出来，统一由状态控制器管理。

## 当前实现

核心脚本：

```text
res://tiny_wizard/status_effects/status_effect_controller.gd
```

脚本类名：

```text
LabStatusEffectController
```

状态控制器不会预先挂在每个敌人身上，而是在第一次有状态施加到目标时自动创建，并作为子节点挂到目标上：

```text
Enemy
└── StatusEffectController
```

这样可以避免给所有单位提前塞节点，也方便后续武器、角色技能和 Boss 技能统一调用。

## 当前状态

### 易伤

当前来源：流影的相位突袭。

效果：

- 持续 3 秒。
- 目标受到伤害提高 20%。
- 目标身上显示橙色状态环。

当前实现方式：

- 状态控制器给目标写入 `lab_vulnerable_damage_multiplier`。
- `QuiverCharacter.hit()` 读取这个 meta 并放大最终伤害。
- 状态过期后，控制器自动清理 meta 和视觉环。

### 减速

当前来源：蜂群的蜂群指令。

效果：

- 持续 2 秒。
- 目标移动速度降低到原速度的 55%。
- 目标身上显示紫色状态环。

当前实现方式：

- 状态控制器记录目标原始 `max_speed`。
- 状态期间修改目标 `physics_stats.max_speed`。
- 状态结束后恢复原始速度。

### 持续伤害

当前来源：蚀瞳的原质寄宿与蚀瞳凝视。

效果：

- 持续按固定间隔造成伤害。
- 目标身上显示绿色状态环。
- 状态刷新时会更新持续时间和 tick 设置。

当前实现方式：

```text
LabStatusEffectController.apply_damage_over_time(target, status_id, duration, damage, tick_interval, visual_color)
```

后续用途：

- 毒液、燃烧、污染区域。
- Boss 的持续污染弹幕。
- 蚀瞳后续的腐蚀扩散和腐蚀引爆。

## 为什么要做这个系统

没有通用系统时，每个状态都要在技能脚本里单独写倒计时、视觉、清理和数值恢复。随着角色、武器和 Boss 增加，这会很快变乱。

状态系统统一处理：

- 状态持续时间。
- 状态刷新。
- 状态到期清理。
- 状态视觉环。
- 易伤、减速、持续伤害等通用逻辑。

## 后续扩展

### 蚀瞳

蚀瞳已经基于状态系统开发第一版：

- 原质寄宿：武器命中时按短冷却施加短腐蚀。
- 蚀瞳凝视：范围污染波会对敌人施加更长腐蚀。
- 后续可以扩展为污染死亡扩散、腐蚀叠层、原质低语和生命换伤害。

### 武器

武器可以附带状态：

- 冰冻枪：施加强减速或定身。
- 毒针枪：施加持续伤害。
- 电弧武器：施加短暂眩晕。
- 腐蚀刀：近战命中叠加腐蚀。

### UI 与反馈

当前只有简单状态环。后续可以继续做：

- 状态图标。
- 叠层数字。
- 状态伤害飘字。
- 敌人血条下方的状态栏。
- 不同状态的粒子特效。
