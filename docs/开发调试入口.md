# 开发调试入口

更新时间：2026-07-03

这个入口用于快速测试正式关卡章节、Boss 前商店、事件房和固定随机种子。当前有两种入口：

- 游戏内入口：角色出生后按 `Control` 打开章节选择窗口。
- Inspector 入口：Godot 中选中 `main.tscn` 根节点后修改开发参数。

两种入口都只用于开发测试，不是正式玩家菜单。

## 游戏内入口

角色完成选择并出生后，按 `Control` 会打开“开发章节入口”窗口。

窗口中可以选择：

- 第一章：极渊前哨基地
- 第二章：生态温室
- 第三章：低温封存区
- 第四章：外骨骼兵器工厂
- 第五章：数据中枢

进入位置可以选择：

- 出生房
- 事件房
- 武器房
- Boss 前补给站
- Boss 房

选择章节后会重置当前探索构筑，仅保留最初选择的角色身份。角色会以满生命、初始专属武器进入目标章节。

入口限制：

- 角色选择界面不能打开。
- 死亡确认界面不能打开。
- 关卡完成结算界面不能打开。
- 暂停菜单打开时不会再打开章节入口。

如果某一章没有对应的事件房、武器房或 Boss 房，游戏会显示提示，不会闪退。

## 入口位置

1. 打开 `tiny_wizard/main.tscn`。
2. 选中根节点 `BioProtocolEntropyZonePrototype`。
3. 在 Inspector 中找到脚本导出参数：
   - `debug_start_chapter`
   - `debug_start_room_type`
   - `debug_override_seed`
   - `dungeon_seed`

## 参数说明

`debug_start_chapter`

- `0`：正常流程，从角色选择 / 教学关开始。
- `1`：直接进入第一章。
- `2`：直接进入第二章。
- `3`：直接进入第三章。
- `4`：直接进入第四章。
- `5`：直接进入第五章。

`debug_start_room_type`

- `none` 或留空：进入该章出生房。
- `start`：进入出生房。
- `pre_boss_shop`：进入 Boss 前固定渡鸦补给站。
- `merchant`：进入渡鸦商店房。
- `event`：进入该章事件房。
- `pollution`：进入污染 / 孢子 / 外骨骼测试类事件房。
- `data_comm`：进入第五章通讯塔控制室。
- `data_satellite`：进入第五章卫星伪装系统。
- `cryo_pod`：进入第三章冷冻舱事件房。
- `weapon`：进入武器房。
- `archive`：进入档案房。
- `boss`：进入 Boss 房。

`debug_override_seed`

- `0`：使用正常随机种子。
- 非 `0`：覆盖本次地牢种子，方便复现同一张地图。

`dungeon_seed`

- 正式关卡生成种子。
- 运行时会在输出台打印当前实际使用的 `seed`。

## 常用测试组合

直接测试第二章事件房：

```text
debug_start_chapter = 2
debug_start_room_type = event
debug_override_seed = 0
```

直接测试第三章 Boss 前补给站：

```text
debug_start_chapter = 3
debug_start_room_type = pre_boss_shop
debug_override_seed = 0
```

直接测试第四章武器质检室：

```text
debug_start_chapter = 4
debug_start_room_type = weapon
debug_override_seed = 0
```

用固定种子复现第五章地图：

```text
debug_start_chapter = 5
debug_start_room_type = none
debug_override_seed = 12345
```

## 注意

- 调试入口会跳过角色选择和教学关，仅用于开发测试。
- 如果要恢复正常流程，把 `debug_start_chapter` 改回 `0`。
- Boss 前商店仍由地图生成器保证固定在 Boss 房前一格；调试入口只是把玩家移动过去。
- 当前入口是轻量开发入口，不是正式玩家菜单。
