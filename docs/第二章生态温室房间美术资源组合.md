# 第二章生态温室房间美术资源组合

本文记录第二章“生态温室”本轮房间美术资源组合方式。目标是把第二章从通用实验室改成“暗黑生化实验室 + 被植物污染的温室”，同时保留现有房间功能、门、宝箱、怪物、渡鸦商人和事件逻辑。

## 资源来源

| 用途 | 素材包 | 项目路径 |
| --- | --- | --- |
| 主要地板、墙体、门框、实验室基础结构 | Top Down Laboratory Tileset - Pixel Art 32x32 by Void Arts | `tiny_wizard/assets/third_party/void_lab_tileset/` |
| 温室结构、水培槽、玻璃墙、植物培养区 | Mars Colony – Greenhouse Module by Maru | `tiny_wizard/assets/third_party/mars_greenhouse/` |
| 培养管、绿色液体、屏幕、终端机、管道、实验室小物件 | Land of pixels - Laboratory pixel art tileset Top down by marceles | `tiny_wizard/assets/third_party/land_of_pixels_lab/` |

Maru 素材以 16x16 图块为主，本轮使用 nearest neighbor 放大到 32x32；Void Arts 和 Land of Pixels 优先使用 32x32 资源。所有合成房间资源由 `tools/build_greenhouse_room_art.py` 生成。

## 碰撞与可玩性

- 中央战斗 / 通行区域保持开阔，不在中央堆叠大型培养柜。
- 大型培养舱、培养区、军械终端、Boss 边缘培养设备、Boss 前室控制台和关键设备均补了 `StaticBody2D` 碰撞体。
- 门口区域保持清晰，避免新增装饰挡住出入口。
- 本轮没有修改怪物配置、宝箱逻辑、渡鸦交易逻辑和地图生成规则。

## 后续可调方向
