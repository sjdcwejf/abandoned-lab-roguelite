# 最终章：母巢核心规划

更新时间：2026-07-06

## 1. 最终章定位

最终章名称固定为“最终章：母巢核心”，内部章节 ID 使用 `99`。它不是“第六章”，也不恢复已经取消的“深层熵区”独立章节。

最终章是《生化协议：熵区》的主线收束章，用来回收前五章的调查、构筑和剧情线索。玩家通过第五章“数据中枢”锁定母体信号后，进入设施最深处。这里已经不是普通实验室，而是被源质、数据线、遗物残响和母体意识重构后的活体核心区。

当前 MVP 一句话定位：

玩家进入最终区域，完成高压战斗、核心终端激活、Boss 前补给和最终 Boss 占位战。强剧情、三结局判定和渡鸦隐藏线只作为后续预留，不在当前主流程强制展示。

## 2. 剧情承接

最终章承接前五章信息：

- 第一章“极渊前哨基地”：事故入口、清理流程、渡鸦据点。
- 第二章“生态温室”：源质造成的生物异化。
- 第三章“低温封存区”：失败适配体被封存、观察和转运。
- 第四章“外骨骼兵器工厂”：弥赛亚动力尝试把源质用于机械战争平台。
- 第五章“数据中枢”：数据终端、通讯控制区、数据封存区、清理协议AI核心室。

第五章完成后，不再提示“第六章：深层熵区”。正确提示为：

最终区域已解锁。

已取消的“深层熵区”不作为独立章节，当前主流程也不再以该名称展示房间。相关概念只保留为后续视觉参考。

## 3. 视觉方向

最终章视觉不是纯实验室、纯肉山或纯赛博空间，而是“被母体重构的设施深处”。

视觉递进：

1. 第五章数据中枢残骸。
2. 源质开始侵蚀设施。
3. 数据线和肉质组织融合。
4. 房间结构逐渐活体化。
5. 母巢核心完全取代原本设施。

颜色比例建议：

- 50% 深灰 / 黑灰金属残骸。
- 20% 暗蓝 / 深蓝数据残留。
- 20% 暗紫源质侵蚀。
- 8% 暗红活体脉冲。
- 2% 冷蓝失效灯光。

地图层级：

- Background Layer：地板、墙体、门框、裂纹、低亮源质纹路、核心干扰图案。
- Decoration Layer：断裂服务器、破损终端、源质根系团、母体连接柱、残留冷却柜。
- VFX Layer：暗紫脉冲、暗红闪烁、蓝紫数据流、节点呼吸光、核心环形脉冲。
- Collision Layer：源质柱、大型根系团、服务器残骸、母体连接柱、巨大管线。

地面源质纹路、核心干扰图案、数据线、裂纹和血管状纹路属于背景贴花，不加碰撞。真实占地的大型源质团、断裂设备、服务器残骸和连接柱才加碰撞，并且不能堵死玩家路线。

## 4. 房间流程

最终章目标时长为 8 到 10 分钟，流程集中，不作为普通大章节扩展。

基础流程：

1. 母巢入口。
2. 高危战斗区。
3. 核心干扰室。
4. 核心终端室。
5. Boss 前战斗区。
6. 补给站。
7. 母巢核心 Boss 房。
8. 中性结局文本占位。

Boss 房前固定为“补给站”。该房间只放渡鸦商人和最终补给终端，不放怪物、宝箱或事件目标。

## 5. 房间功能说明

### 母巢入口

类型：出生房 / 章节入口房。

目标：进入母巢深处。

视觉：第五章数据中枢残骸仍然可见，深灰金属地板、断裂数据通道、墙角暗紫源质根系和失效冷蓝灯带共同表现“刚进入最终区域”。

### 高危战斗区

类型：普通战斗房 / 过渡房。

目标：清除房间内异常单位。

视觉：深灰金属地板被暗紫裂纹切开，数据线断裂错位，墙边源质根系增加。该房间用于表现最终区域压力，不作为独立章节或强剧情过渡。

### 核心干扰室

类型：非战斗机制房。

目标：激活核心终端。

玩法：房间不刷怪，不弹三选一，不记录回应状态。玩家激活核心终端后，显示“核心干扰已清除。出口已开启。”并打开出口。

视觉：中央功能平台、低亮暗紫干扰环、残留暗蓝数据线从墙面汇入平台，整体安静且压迫。

### 核心终端室

类型：功能终端房。

目标：激活核心终端。

当前主流程：

- 不弹长剧情文本。
- 不写入主流程剧情档案。
- 不触发隐藏线索或结局提示。
- 只显示“终端已激活。”并完成房间目标。

后续版本可以在可选路线或专门剧情入口中重新接入长文本档案。

### Boss 前战斗区

类型：Boss 前压力战斗房。

目标：清除战斗区内异常单位。

玩法：复用前几章敌人作为被母体重构后的异常单位。第一版不新增正式敌人。

视觉：金属设施大面积被源质侵蚀，但仍保留可辨认移动路线。

### 补给站

类型：最终 Boss 前固定商店房。

目标：最后整备。

规则：不放怪物、不放宝箱、不放事件目标，只放渡鸦商人和最终补给终端。

当前主流程只显示补给机制反馈。渡鸦隐藏线对话保留为后续可选内容，不在当前主流程强制展示。

### 母巢核心 Boss 房

类型：最终 Boss 房。

Boss 名称：核心 Boss（占位）。

第一版只做占位 Boss。玩家进入 Boss 房后激活，击败后触发中性结局文本占位。Boss 不在玩家进入前隔墙攻击。

视觉：中央巨大核心、多层环形核心干扰纹路、外圈可移动路线、四周活体化墙体和断裂数据线。

## 6. 后续 Boss 设计规划

当前主流程只使用核心 Boss 占位。以下内容为后续版本规划，不在当前主流程强制实现。

后续技能：

- 母体脉冲：从中心释放圆形脉冲，地面提前出现预警圈。
- 核心干扰回声：根据后续可选剧情或隐藏路线改变 Boss 阶段提示或结局权重。
- 样本召唤：召唤少量前几章敌人，低血量阶段混合召唤。

阶段规划：

- 第一阶段：核心苏醒，血量 100%-70%，攻击慢，以母体脉冲和少量召唤为主。
- 第二阶段：护盾启动，血量 70%-40%，通过核心节点或护盾表现压力。
- 第三阶段：核心暴露，血量 40% 以下，攻击频率提高，后续可接入结局权重。

## 7. 结局路线规划

当前第一版只显示中性通关文本，不做完整动画和复杂判定。以下路线保留为后续规划，不在当前主流程强制展示。

### 召回结局

方向：遗物融合程度较高、携带遗物较多或使用高危遗物。

文本占位：

你切断了母巢核心，却听见体内遗物回应了另一个声音。母体已死。召回仍在继续。

### 纯净结局

方向：遗物融合程度较低，没有深度绑定遗物。

文本占位：

母体信号逐渐熄灭。你没有回应召回。熵区第一次真正安静下来。

### 逆命结局

方向：玩家在极低血量或异常削弱状态下击败母体，并满足隐藏条件。

文本占位：

协议无法识别你的状态。母体无法召回你。你也不再属于原来的生命序列。

## 8. 渡鸦隐藏线回收预留

最终章后续可以用于回收第五章或更早章节预留的渡鸦隐藏任务线。

当前主流程保留 `raven_hidden_quest_unlocked` 等 flags，但不主动展示隐藏文本、不展开完整任务链和奖励。

回收核心：

后续隐藏线可以继续探索渡鸦旧债、公司隐瞒和最终章选择，但应放在可选路线或专门剧情入口中。

## 9. 与第五章数据中枢的衔接

第五章完成后解锁最终章入口：

- 正式流程：第五章完成后回到临时安全屋，选择遗物后进入最终章。
- 调试流程：开发章节入口可直接进入最终章，并保留当前武器、词条、遗物、货币、血量、渡鸦线索和结局提示。

第五章不再指向“第六章：深层熵区”。当前主流程不再显示“深层熵区”房间名；如后续使用该概念，仅作为视觉参考或可选内容。
