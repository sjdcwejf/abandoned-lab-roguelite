# 最终章：母巢核心规划

更新时间：2026-07-06

## 1. 最终章定位

最终章名称固定为“最终章：母巢核心”，内部章节 ID 使用 `99`。它不是“第六章”，也不恢复已经取消的“深层熵区”独立章节。

最终章是《生化协议：熵区》的主线收束章，用来回收前五章的调查、构筑和剧情线索。玩家通过第五章“数据中枢”锁定母体信号后，进入设施最深处。这里已经不是普通实验室，而是被源质、数据线、遗物残响和母体意识重构后的活体核心区。

一句话定位：

玩家抵达母体信号源，面对母体召回协议，并根据此前遗物、渡鸦旧债和结局提示进入不同结局路线。

## 2. 剧情承接

最终章承接前五章信息：

- 第一章“极渊前哨基地”：事故入口、清理流程、渡鸦据点。
- 第二章“生态温室”：源质造成的生物异化。
- 第三章“低温封存区”：失败适配体被封存、观察和转运。
- 第四章“外骨骼兵器工厂”：弥赛亚动力尝试把源质用于机械战争平台。
- 第五章“数据中枢”：母体诱饵假说、公司隐瞒、渡鸦旧债。

第五章完成后，不再提示“第六章：深层熵区”。正确提示为：

母体信号已锁定。最终章：母巢核心，入口已开启。

“深层熵区”只保留为最终章内部的过渡房概念，用来表现现实空间开始被母体信号扭曲。

## 3. 视觉方向

最终章视觉不是纯实验室、纯肉山或纯赛博空间，而是“被母体重构的设施深处”。

视觉递进：

1. 第五章数据中枢残骸。
2. 源质开始侵蚀设施。
3. 数据线和肉质组织融合。
4. 房间结构逐渐活体化。
5. 母巢核心完全取代原本设施。

颜色比例建议：

- 50% 深灰 / 黑灰金属残骸。
- 20% 暗蓝 / 深蓝数据残留。
- 20% 暗紫源质侵蚀。
- 8% 暗红活体脉冲。
- 2% 冷蓝失效灯光。

地图层级：

- Background Layer：地板、墙体、门框、裂纹、低亮源质纹路、召回协议图案。
- Decoration Layer：断裂服务器、破损终端、源质根系团、母体连接柱、残留冷却柜。
- VFX Layer：暗紫脉冲、暗红闪烁、蓝紫数据流、节点呼吸光、核心环形脉冲。
- Collision Layer：源质柱、大型根系团、服务器残骸、母体连接柱、巨大管线。

地面源质纹路、召回协议图案、数据线、裂纹和血管状纹路属于背景贴花，不加碰撞。真实占地的大型源质团、断裂设备、服务器残骸和连接柱才加碰撞，并且不能堵死玩家路线。

## 4. 房间流程

最终章目标时长为 8 到 10 分钟，流程集中，不作为普通大章节扩展。

基础流程：

1. 母巢入口。
2. 深层熵区过渡房。
3. 母体审讯室。
4. 母体信号室。
5. 原初母巢前庭。
6. 渡鸦最终补给站。
7. 母巢核心 Boss 房。
8. 结局文本占位。

Boss 房前固定为“渡鸦最终补给站”。该房间只放渡鸦商人和最终补给终端，不放怪物、宝箱或事件目标。

## 5. 房间功能说明

### 母巢入口

类型：出生房 / 章节入口房。

目标：进入母巢深处。

视觉：第五章数据中枢残骸仍然可见，深灰金属地板、断裂数据通道、墙角暗紫源质根系和失效冷蓝灯带共同表现“刚进入最终区域”。

### 深层熵区过渡房

类型：普通战斗房 / 过渡房。

目标：清理房间内异常样本。

视觉：深灰金属地板被暗紫裂纹切开，数据线断裂错位，墙边源质根系增加。它吸收“深层熵区”概念，但不作为独立章节。

### 母体审讯室

类型：非战斗剧情选择房 / Boss 前立场确认房。

目标：回应母体信号。

玩法：房间不刷怪、不生成召回节点。玩家进入后触发“母体信号接入”界面，在“拒绝接入”“短暂接入”“反向篡改”中选择一种回应方式。选择结果只记录运行期剧情标记，不清空遗物、不禁用装备。

视觉：中央审讯平台、低亮暗紫协议环、残留暗蓝数据线从墙面汇入平台，整体安静且压迫。

### 母体信号室

类型：剧情房 / 档案房。

目标：读取母体信号记录。

档案占位：

- 《母体召回协议》
- 《适配个体筛选记录》
- 《渡鸦旧债最终片段》

如果渡鸦隐藏任务线已开启，后续可显示额外隐藏文本，回收渡鸦旧债。

### 原初母巢前庭

类型：Boss 前压力战斗房。

目标：清除母巢前庭内的重构样本。

玩法：复用前几章敌人作为被母体重构后的异常单位。第一版不新增正式敌人。

视觉：金属设施大面积被源质侵蚀，但仍保留可辨认移动路线。

### 渡鸦最终补给站

类型：最终 Boss 前固定商店房。

目标：最后整备。

规则：不放怪物、不放宝箱、不放事件目标，只放渡鸦商人和最终补给终端。

普通对话方向：

渡鸦：前面就是母巢核心。

渡鸦：进去之后，我可能无法再联系你。

隐藏线开启后的对话方向：

渡鸦：你已经知道那些记录了。

渡鸦：那扇门不是我第一次打开的。

渡鸦：但我确实把后来的人送了进去。

### 母巢核心 Boss 房

类型：最终 Boss 房。

Boss 名称：原初母体。

第一版只做占位 Boss。玩家进入 Boss 房后激活，击败后触发结局文本占位。Boss 不在玩家进入前隔墙攻击。

视觉：中央巨大核心、多层环形召回协议纹路、外圈可移动路线、四周活体化墙体和断裂数据线。

## 6. 原初母体 Boss 设计规划

本次不完整实现 Boss 行为，只记录后续设计。

后续技能：

- 母体脉冲：从中心释放圆形脉冲，地面提前出现预警圈。
- 母体审讯回声：根据母体审讯室的回应方式改变 Boss 阶段提示或结局权重。
- 样本召唤：召唤少量前几章敌人，低血量阶段混合召唤。

阶段规划：

- 第一阶段：核心苏醒，血量 100%-70%，攻击慢，以母体脉冲和少量召唤为主。
- 第二阶段：召回协议启动，血量 70%-40%，开始读取玩家在母体审讯室中的回应状态。
- 第三阶段：协议崩解，血量 40% 以下，攻击频率提高，回应状态影响后续结局判定。

## 7. 结局路线规划

第一版只做文本占位，不做完整动画和复杂判定。

### 召回结局

方向：遗物融合程度较高、携带遗物较多或使用高危遗物。

文本占位：

你切断了母巢核心，却听见体内遗物回应了另一个声音。母体已死。召回仍在继续。

### 纯净结局

方向：遗物融合程度较低，没有深度绑定遗物。

文本占位：

母体信号逐渐熄灭。你没有回应召回。熵区第一次真正安静下来。

### 逆命结局

方向：玩家在极低血量或异常削弱状态下击败母体，并满足隐藏条件。

文本占位：

协议无法识别你的状态。母体无法召回你。你也不再属于原来的生命序列。

## 8. 渡鸦隐藏线回收

最终章用于回收第五章开启的渡鸦隐藏任务线。

如果 `raven_hidden_quest_unlocked` 为真，临时安全屋、母体信号室或渡鸦最终补给站可以显示隐藏文本。第一版只保留短对话，不展开完整任务链和奖励。

回收核心：

渡鸦确实打开过门，但他不是第一个发出信号的人。母体可能借由公司通讯系统释放诱饵，让外部个体进入熵区。

## 9. 与第五章数据中枢的衔接

第五章完成后解锁最终章入口：

- 正式流程：第五章完成后回到临时安全屋，选择遗物后进入最终章。
- 调试流程：开发章节入口可直接进入最终章，并保留当前武器、词条、遗物、货币、血量、渡鸦线索和结局提示。

第五章不再指向“第六章：深层熵区”。如果出现“深层熵区”，只能指最终章内部的过渡房。
