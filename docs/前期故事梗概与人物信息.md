# 前期故事梗概与人物信息

本文档整理自 `aaa.doc`，作为《生化协议：熵区》的前期故事、角色、美术与流程参考。后续如果与主设定文档冲突，以团队最新确认版本为准。

## 1. 背景

### 1.1 实验岛屿

实验岛屿能提供更多区域变化：港口、外部营地、研究楼、地下设施、温室、生物巢穴、反应堆、海底通道等，也更适合后续多人联机与章节推进。

### 1.2 极渊岛

《生化协议：熵区》的故事发生在一座被地图抹除的孤岛：极渊岛。

这座岛表面上是弥赛亚动力的极地生态研究基地，实际上地下隐藏着庞大的原质实验设施。原质爆发后，岛上所有通讯被公司切断，研究员、安保人员和实验体几乎全部失联。

数周后，一段加密求救信息突破封锁，被流亡军火商“渡鸦”截获。信息中提到：原质并未被控制，实验岛地下仍有休眠舱存活信号，并且怪物正在沿着地下排水系统和海岸裂隙向外扩散。

渡鸦曾参与这座岛屿的建设，也知道岛下封存着弥赛亚动力最危险的实验成果。出于利益、旧债和对灾难扩散的恐惧，他决定重返实验岛，唤醒休眠仓中的改造者，并以交易的方式引导他们深入熵区。

### 1.3 地图主题

第一章暂定为“封存协议”：一座刚刚从冷冻封存中死去的实验室。

前半段保留冷白、蓝光、玻璃、金属、休眠仓等干净科技感。中段出现破碎培养罐、遇害研究员、失控安保系统和少量原质污染。后半段逐渐变成半实验室半生物巢穴，黑蓝色原质脉络沿地板与墙面蔓延，红色警报灯不断闪烁。玩家在渡鸦的引导下从苏醒、拿起武器、学习战斗，最终面对第一个失格实验体。

第一章不要把恐怖感拉满，而要让玩家感觉：这里曾经是实验室，现在正在变成怪物的胃。

互动元素应统一视觉：

- 越靠近污染中转区，地图越杂乱、越暗、越有生物质。
- 地面设计：生物膜、原质结晶，以绿色为主调，避免红色过多导致画面花眼；倒地实验员可参考《孤胆枪手》的环境叙事。
- 墙面设计：活体组织包裹管道、蠕动纹理、破损隔离门、被污染的监控镜头。
- 可开启门：蓝色灯。
- 锁定门：红色灯。
- 商人补给：黄色灯加渡鸦标记。
- 原质经验：蓝黑发光碎片。
- 危险污染：暗红脉动边缘。

> 术语备注：当前项目统一使用“原质 / Protomatter”，击杀敌人掉落的局内资源称为“原质碎片 / Protomatter Fragments”。

## 2. 角色

### 2.1 流影

关键词：第一代改造者、高机动、神经反射强化、轻装突击、残影、迅捷、冷峻。

流影的美术设计应突出“第一代高机动改造实验体”的身份。整体以黑色与深灰色轻型作战服为主体，搭配破损的实验约束服残片和单侧白色肩甲。肩甲上保留“A-07”实验编号或弥赛亚动力旧警示标识。

整体轮廓应修长、前倾、轻盈，避免厚重装甲。重点强化腿部设计，使小腿、膝关节和推进靴呈现明显机械义体结构，并以冰蓝色发光线路表现神经驱动与高速机动能力。

面部气质冷峻、沉默、略带实验苏醒后的疲惫感。太阳穴、颈部或耳侧可以加入粗糙的第一代神经植入接口，体现其并非成熟产品，而是早期实验品。眼下可有淡淡蓝色裂纹状血管；动作时耳侧植入体发光；冲刺后小腿周围短暂出现类似生物脉冲的残影，说明体内有活性的改造组织在运作。

背后可加入短披片、破损围巾或半透明蓝色残影拖尾，用于表现“瞬影突进”技能与残影诱饵机制。整体风格是近未来军工、生化实验体与像素地牢射击角色的结合，主色为黑、灰、白，强调色为冰蓝。

玩法节奏：

- 移动。
- 冲刺。
- 留下残影。
- 聚怪。
- 爆裂或射击。
- 击杀后继续加速。

### 2.2 铁幕

关键词：第一代改造者、重装、护盾、安保出身、厚重、防线。

铁幕是正面承受怪潮冲击的移动防线。整体体型应宽厚、低重心、压迫感强。主体使用枪铁灰、深军绿和暗黑色重型装甲，搭配旧式实验支撑结构、破损安保装甲残片和粗糙外骨骼框架，体现第一代改造技术的笨重与不成熟。

胸口、脊柱、肩部和前臂应有明显机械加固结构。前臂可装备大型护盾发生器，背部连接沉重电源组或稳定器。装甲表面保留“A-12”实验编号、弥赛亚动力安保标识、划痕、酸蚀和弹孔。

生物改造感体现在装甲与身体接口处的粗大植入环、脊柱神经接驳管、强化肌肉束和旧手术疤痕，让人感觉他并不是穿上重甲，而是身体已经被强行改造成承载重甲的平台。

技能路线可以通过升级池、Boss 掉落或渡鸦商店获得：

- 承受怪潮。
- 展开护盾。
- 吸收伤害。
- 反击爆裂。
- 重火力压制。
- 反弹伤害。

候选技能方向：

- 生物熔炉：吸收伤害并转化为火力，消耗回灌值强化护盾爆炸，适合反击流。
- 重力震荡：使周围怪物减速，周期性对周围敌人造成震荡伤害。
- 失控壁垒：护盾值大幅提升，护盾破裂时造成巨大原质爆炸；生命越低，伤害和减伤越高。

### 2.3 蜂群

关键词：第二代改造者、无人机控制、神经集群接口、战术支援、模块化、冷静、精密。

相比第一代改造者，蜂群外观应更整洁、更轻量、更模块化，体现弥赛亚动力改造技术从粗暴人体实验向成熟战术系统过渡。

整体体型中等偏修长。服装以冷白、灰蓝和石墨灰色轻型科技作战服为主，搭配可展开式背部无人机控制架、腰部模块仓、头部通讯接口和手腕战术终端。核心识别点不是重武器，而是围绕身体悬浮的小型无人机、背后的集群控制装置和青绿色数据链路光效。

生物改造感可体现在头侧、后颈和脊柱处的神经接口，像是大脑被直接接入无人机网络。眼部可加入半透明 HUD 投影或一侧机械义眼，表现其长期连接系统后的冷静、疏离与轻微非人感。

蜂群不需要大面积伤疤，而应通过精密接口、同步灯点、微型线缆和神经链接纹路体现“人类作为集群控制核心”的设定。整体视觉关键词是：模块化、无人机、支援、冷白科技、集群意识、精密控制。

### 2.4 蚀瞳

关键词：第三代改造者、原质共生、腐蚀、污染扩散、异化感、危险、神秘。

蚀瞳应突出“第三代原质共生实验体”的身份，是四人中最接近非人的存在，外观表现出生物组织、原质污染与人体共生后的不稳定美感。

整体体型可偏纤细、安静、不对称。服装以暗灰、黑紫和破损实验拘束服为主体，部分防护层与身体被原质侵蚀融合。肩颈、手臂、胸侧或腿部一侧可以出现发光裂纹、黑紫色生物膜、半透明组织、细小触须或结晶化纹路。

最重要的识别点是“蚀瞳”的眼部设计：一只眼可以变为毒绿、荧紫或病态青白色的原质异化眼，像能看见怪物体内的数据流与污染脉动。

蚀瞳的生物改造感应强于其他角色，体现为皮肤下流动的原质脉络、腐蚀雾气、孢子粒子、身体一侧逐渐非人化的轮廓。但仍要保留人形和克制的表情，让玩家感觉她/他不是怪物，而是正在努力维持自我的实验体。技能特效可围绕腐蚀领域、毒雾、污染波纹和原质低语展开。

### 2.5 渡鸦 Raven

代号“渡鸦”，真实姓名不明。外表是一名神秘的流浪军火商兼拾荒者，常年穿着厚重的旧式防护服，脸上戴着鸟嘴医生风格的防毒面具。防毒面具内传出的声音沙哑低沉。他说话总是半真半假，语气玩世不恭，似乎任何灾难在他眼里都可以被标上价格。

渡鸦曾是“弥赛亚动力”的中层技术主管，参与过“极渊”实验室早期建设、物资调度和部分安全协议设计。他并非最核心的科学家，却足够接近真相。在一次内部审查中，他发现公司正在以“适格者计划”为名进行大规模活体实验，并试图将“原质”开发为可军事化的生物重组技术。

当他试图向外界泄露资料时，公司将他列为清除对象。渡鸦利用一次实验事故伪造死亡记录，从极渊系统中抹去了自己的身份。此后，他流亡于各个黑市据点之间，靠倒卖军用装备、企业机密和禁用技术为生。

“原质”灾难爆发后，渡鸦独自返回南极。他对外宣称自己只是嗅到了商机，想在弥赛亚动力彻底封锁现场前捞走最值钱的数据和装备。但实际上，他很清楚极渊深处还沉睡着一批“适格者”实验体。那些人中，有些曾经是被他亲手送入设施的“货物”，也有些曾经是他的同事、护卫或测试对象。

渡鸦唤醒主角们，并不是出于纯粹的善意。他需要这些实验体替他打开封锁区域、清理怪潮、回收研究数据。作为交换，他提供武器、弹药、医疗针、外骨骼模块和被他改造过的黑市装备。玩家需要用从实验室中搜集到的研究数据向他购买商品。

他不是圣人，也不自称救世主。他会趁火打劫，会隐瞒关键信息，也会在玩家最狼狈的时候抬高价格。但在真正的绝境中，渡鸦往往又是唯一一个还愿意打开通讯频道的人。

他对主角们的态度始终矛盾。一方面，他把实验体称作“冰柜里的货”“弥赛亚留下的坏账”；另一方面，他比任何人都清楚他们曾经遭遇过什么。随着剧情推进，玩家会逐渐发现，渡鸦回到极渊并不只是为了赚钱。他欠这座实验室里的人一笔旧债，而现在，他试图用最不体面的方式偿还它。

## 3. Boss

### 3.1 第一章：教学性质的精英怪

名称：失格者 A-03：破仓体。

设定：它曾经是第一代改造实验体之一，在原质泄露后从休眠舱中提前苏醒，但没有保持理智，被原质吞噬后变成半人半怪的失败品。

地点：失败实验体回收室。

美术表现：

- 中央有一个巨大破碎休眠舱，半实验室半巢穴。
- 仓体比玩家的仓更旧。
- 地上有很多拖拽痕迹。
- 墙上写着“第一代适格者回收”。
- 原质组织从仓体内部向外蔓延。
- Boss 从破碎舱中爬出。

这个 Boss 可以和流影、铁幕的第一代背景直接产生联系。

## 4. 流程

### 4.1 开场界面

主菜单出现前，渡鸦可以说：

> “收到这段泄露信号的时候，我就知道：这座岛还欠我一笔账。”

随后画面亮起，标题出现：《生化协议：熵区》。

开场界面应以“极渊岛地下实验室休眠仓大厅”为核心场景，画面呈现冷白实验室与原质污染并存的状态：破损休眠仓、闪烁警报灯、断裂线缆、碎玻璃、营养液水洼和黑蓝色原质脉络共同构成背景。

主菜单不是普通 UI，而是弥赛亚动力遗留终端界面。按钮以“启动清理协议、选择适格者、查看实验档案”等形式呈现。画面中休眠仓编号 A-07、A-12、B-04、C-19 间歇闪烁，仓内角色剪影随维生灯微弱起伏。远处偶尔有怪物影子掠过，墙角原质组织缓慢蠕动，终端信号中不时插入渡鸦的通讯。

整体氛围应冷峻、压抑、危险但不混乱，让玩家在进入游戏前就感受到：这座岛已经死亡，而休眠仓中的改造者是最后的清理筹码。
