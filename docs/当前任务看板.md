# 当前任务看板

更新时间：2026-06-30

这个文件用于记录项目当前共识、进行中的任务、下一步顺序和暂缓内容。之后每次问“下一步做什么”时，优先读取本文件，再结合 `CHANGELOG.md` 和相关设计文档判断。

## 当前总方向

项目目标是制作面向 Steam 的 2D 像素风、俯视角 / 斜俯视角、房间制动作 Roguelite 游戏。

核心体验保持为：

- 进房间
- 清怪
- 拿资源
- 换武器 / 买武器 / 形成构筑
- 击败 Boss
- 进入下一层或下一章

当前项目重点从“基础可玩原型”进入“武器路线 + 地图章节化”的阶段。

## 已确认设计共识

- `原质` 与 `源质` 是同一种核心物质。当前游戏内显示暂以“原质”为主，后续文档中出现的“源质”视为同一设定概念。
- 游戏成长分为两条路线：
  - 遗物路线：以遗物为核心增强战斗力。
  - 武器路线：不依赖遗物，通过武器获取、替换、购买和强化增强战斗力。
- 普通怪主要掉落原质。
- 精英怪主要掉落遗物。
- 武器主要来自宝箱和渡鸦商人。
- 渡鸦后续需要提供遗物回收功能，玩家可以把遗物换成原质，用于支持武器路线。
- 当前先凯负责的重点是武器路线和地图开发。
- 项目规划为七章结构。排除原始 / 初始武器后，武器路线至少需要设计 14 种武器。
- 章节顺序已确认：第二章生态温室，第三章低温封存区，第四章外骨骼兵器工厂。
- “人体适配失败”是世界观背景和档案线索，不再作为独立章节；当前不新增角色专属升级、主动技能强化、源质污染值、技能树或新的成长系统。

## 当前进行方向

### 方向一：武器路线系统

目标：让不走遗物路线的玩家，也能通过武器获取和武器构筑形成稳定成长。

下一批任务：

1. 在武器目录中补充“已实装 / 未实装”标记，避免后续章节武器提前进入掉落池。
2. 继续补第一章第 2 把新增武器，建议从控制类或短程爆发类里选择。
3. 让宝箱和渡鸦商人后续可以根据章节、层数或房间深度调整可售武器权重。
4. 第二章开始前，至少完成孢子喷雾器或根须钉枪中的一把。

### 方向二：地图章节化

目标：从当前通用实验室随机房间，逐步升级为七章结构。

七章暂定方向：

1. 极渊前哨基地
2. 生态温室
3. 低温封存区
4. 外骨骼兵器工厂
5. 数据中枢
6. 深层熵区
7. 母巢核心

下一批任务：

1. 为第三章低温封存区补最终 tileset 房间美术，逐步替换当前程序化低温覆盖层。
2. 验证第三章低温减速、冷冻舱检查、低温喷口和精英守卫节奏是否清楚。
3. 补充第三章封存记录终端、失败适配体观察记录、样本转运通道和兵器工厂访问权限线索。
4. 继续微调第二章和第三章房间障碍，避免装饰影响主通路。
5. 让宝箱、武器房和渡鸦商人根据章节读取武器池与权重。
6. 根据 `docs/地图章节规划.md` 继续调整七章时长和房间数量。

### 方向三：原质与遗物边界

目标：以海天分支的构筑遗物方向为准，先保证遗物可拾取、可显示、可回收，再逐步扩展完整遗物路线。

已完成：

- 当前玩家可见核心资源统一显示为“原质”。
- 新增海天分支的构筑遗物系统，支持中立遗物、角色专属遗物、标签、堆叠、移除和协同。
- 左侧遗物 HUD 可显示已拥有遗物和融合状态，背包资源栏也会统计遗物数量。
- 关卡 Boss 通过遗物池掉落合法构筑遗物。
- 渡鸦商人可回收 1 个遗物，换取 5 个原质。
- 当前遗物路线已存在第一批真实效果：事件触发、护盾 / 回复、反震、护盾减伤和静态参数加成。
- 当前遗物数值仍是原型参数，后续需要继续验证强度、掉落节奏和回收价值。

下一批任务：

1. 设计精英怪与 Boss 的遗物掉落差异。
2. 设计遗物详情面板，让玩家能查看遗物效果、标签和协同条件。
3. 决定遗物路线是否需要局内强化、反噬或回收损耗。
4. 等武器路线稳定后，再扩展完整遗物效果。
