# 中文文本与字体规范

本文档用于避免游戏内中文显示成乱码、方块或缺字。

## 当前规则

- 游戏内可以使用中文文本。
- 所有中文 UI 依赖 `res://tiny_wizard/gui/chinese_font_bootstrap.gd` 安装中文字体，并对 UI 控件树强制应用字体覆盖。
- 主场景 `tiny_wizard_main.gd` 会在启动时调用字体安装，并在生成教学/正式房间后重新应用到房间 UI。
- 角色选择界面、GUI、技能 HUD、背包、Boss 血条和渡鸦商店都会独立调用字体应用，方便单独预览对应界面。
- 仓库根目录的 `.editorconfig` 已统一文本文件使用 UTF-8 编码。

## 字体来源

当前项目优先尝试加载项目内字体路径：

- `res://tiny_wizard/assets/fonts/NotoSansSC-Regular.otf`
- `res://tiny_wizard/assets/fonts/NotoSansCJKsc-Regular.otf`
- `res://tiny_wizard/assets/fonts/SourceHanSansSC-Regular.otf`
- `res://tiny_wizard/assets/fonts/SourceHanSansCN-Regular.otf`

如果项目内没有字体，会按 macOS、Windows、Linux 的常见系统中文字体路径查找。这样本机开发不会乱码，也不会把系统字体直接提交到仓库。

## 后续建议

正式发布前，建议加入一套可商用、可随项目分发的开源中文字体，例如 Noto Sans SC 或思源黑体，并放入 `tiny_wizard/assets/fonts/`。这样 Steam 导出包在 Windows、macOS、Linux 上都会稳定显示中文。

## 更新要求

- 新增或修改中文文案时，保持文件为 UTF-8 编码。
- 新增玩家可见 UI 时，需要调用 `LabChineseFontBootstrap.apply_to_tree(...)`，不能只依赖默认 fallback。
- 以后新增中文 UI 后，需要至少做一次 Godot headless 加载检查。如果看到 `No Chinese-capable UI font found` 警告，说明当前机器或导出环境没有可用中文字体，需要先补项目内字体。
